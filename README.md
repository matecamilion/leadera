\# Leadera — CRM Inmobiliario



CRM para gestión y seguimiento de leads inmobiliarios.



\## Estructura



\- `leadera/` — Backend (Java + Spring Boot + MySQL)

\- `leadera-front/` — Frontend (Angular)



\## Requisitos



\- Java 17+

\- Node.js 18+

\- MySQL 8+

\- Maven



\## Cómo correr en local



\### Backend

\\`\\`\\`bash

cd leadera

./mvnw spring-boot:run

\\`\\`\\`



\### Frontend

\\`\\`\\`bash

cd leadera-front

npm install

npm start

\\`\\`\\`
